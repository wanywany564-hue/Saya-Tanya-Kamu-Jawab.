# Saya-Tanya-Kamu-Jawab.
Saya Tanya, Kamu Jawab ialah sebuah permainan interaktif berasaskan audio yang direka khusus untuk murid Tahun 4. Permainan ini menggabungkan aktiviti mendengar soalan dan merakam jawapan lisan bagi meningkatkan kemahiran mendengar dan bertutur Bahasa Melayu sambil memupuk kesedaran kebersihan kantin sekolah.
